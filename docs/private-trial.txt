RichoMonitor 小范围试用

Mac 安装

Mac 需要 macOS 13 或更新系统。Apple Silicon 选择 aarch64.dmg，
Intel Mac 选择 x64.dmg；请下载与电脑处理器对应的安装包。
打开 DMG，将 RichoMonitor 拖入 Applications（应用程序），
弹出磁盘映像，再从应用程序打开。

此试用包采用临时签名，尚未经过 Developer ID 签名与 Apple 公证。
首次打开可能提示无法验证开发者。如果你确认安装包来自可信提供者，
尝试打开后进入系统设置 → 隐私与安全性，找到此应用并点击“仍要打开”，
然后在确认窗口中点击“打开”。受单位管理的电脑可能禁止此操作。
Apple 的操作说明：https://support.apple.com/zh-cn/102445

Windows 安装

运行 x64-setup.exe，按安装向导完成安装。本次已在 Windows 11 x64 虚拟机验证。
此包尚无 Authenticode 签名，系统可能提示未知发布者，请确认来源后继续。
Windows 10 与其他实机环境仍待补充验收。

首次使用

完成商品选择后，可允许系统通知、测试突出提醒并扫码添加通知渠道。
首次开启突出提醒会引导测试。通知权限可在系统设置中调整。
通知账号与监控数据均保存在你自己的电脑；安装包不含开发者的账号、
商品选择、聊天对象或消息记录。关闭主窗口后应用继续在后台运行，
需要停止时从菜单栏菜单选择退出。

应用更新

应用启动时及运行期间每小时检查新版本，默认自动下载，
在监控停止、暂停或计划时段外自动安装。下载期间继续监控，
安装与重启时短暂中断，随后恢复原运行意图。其他设置中可关闭自动更新；
手动立即更新需要确认中断监控。
现有未接入更新功能的试用版本需要手动安装一次带更新功能的版本。

试用反馈

请提供系统版本、发生时间、操作步骤与可见现象。截图前请遮盖二维码、
账号信息及聊天内容。扫码授权过期、机器人被移出群聊或平台权限变化时，
请在通知页面查看状态并按提示重新连接。

长时间睡眠唤醒、网络切换、专注模式、外部全屏应用、真实注销登录启动
及连续多日运行仍在补充实机验收。试用时请结合商城确认库存与价格。
