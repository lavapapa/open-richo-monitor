# 桌面发版验收清单

正式分发前逐项完成以下真实环境验收。状态“待验”表示尚无满足该场景的真实环境证据；每次发版检查时向用户提醒仍然待验的项目。执行后记录机型、系统版本、起止时间、结果和相关证据。

## macOS

1. **部分完成：Intel Mac。** 2026-10-08，macpro2021（Xeon W-3265M）、macOS 14.1.2：x64 原生构建、安装启动、商品图片、设置引导、突出提醒与 Esc 关闭、退出重开，以及内置 Bun 1.4.2 基础测试通过。托盘交互、通知授权、系统通知实际横幅与真实账号投递仍待验。
2. **待验：跨日睡眠与唤醒。** 在计划时段内外睡眠并跨日唤醒，检查北京时间计划、监控恢复、检查计数与通知队列。
3. **待验：断网与网络切换。** 运行中断网、恢复及切换网络，检查请求恢复、渠道重连、提醒时效和重复投递。
4. **待验：专注模式与屏幕共享。** 开启、关闭以及计划切换专注模式；分别在镜像或共享屏幕时允许、关闭通知，观察系统通知横幅、通知中心记录和突出提醒各自表现。
5. **待验：全屏应用。** 当前显示器存在全屏应用时触发突出提醒，检查可见性、键盘关闭与原应用焦点恢复。
6. **待验：实际注销与登录启动。** 开启登录后启动，真实注销再登录，检查启动路径、运行意图与计划等待；关闭此选项后再次验证。
7. **待验：多日资源变化。** 连续运行多日，交替发生多商品上架、库存增加、重复观察及短时事件密集到达，记录内存、CPU、磁盘和队列变化。

## Windows

安装验收在真实客户端系统执行，记录 Windows 版本与应用身份；Windows Server 构建通过分别记为自动化结果。用户反馈的系统版本纳入复现范围。

1. 首次安装与通知：新应用数据和通知注册状态下查询权限、发送、通知历史、系统关闭后重新开启，以及窗口反复失焦和聚焦；区分读取失败、拒绝和系统接受。
2. 提醒显示：热键分别被占用、图片解码延迟、其他应用前台、全屏、多显示器和不同缩放；锁屏保留待展示事件，解锁后显示，关闭后快捷键恢复。
3. 运行生命周期：关闭窗口继续监控、托盘重开与 Explorer 重启、断网重连、睡眠唤醒、真实注销登录和多日资源变化；实际请求与通知队列分别记录。
4. 安装与渠道：缺少 WebView2、覆盖安装、更新中断及卸载；各平台新账号首次发送、重新打开后发送、权限不足和限流分别验证。PAC、WPAD、静态绕过、HTTP 与 WebSocket 走同一系统代理策略。

`regression.yml` 在两个平台执行共享回归；Windows WebView 与原生命令入口为 `scripts/test-windows-desktop.mjs`，由 tauri-driver 启动隔离实例。该入口的通过不替代系统横幅、锁屏及真实账号接收证据。耐久测试记录吞吐与资源，历史数量淘汰由 `Storage::each_new_history_row_keeps_both_sources_bounded_and_outbox_intact` 的定量测试独立验证。

当前版本以 [tauri.conf.json](../apps/desktop/src-tauri/tauri.conf.json) 的 `version` 为准。公开分发还需确认签名与公证、发行下载链接以及第三方许可声明。

2026-10-07，Apple Silicon（Mac16,8）、macOS 26.6.2：系统日志证实屏幕共享且关闭通知时，消息进入通知中心历史，横幅被 `displayShared` 抑制。用户授权将共享时通知设为允许后，dev 测试的系统日志记录实际显示横幅，用户确认已看到。调试 App 完整签名后通过严格校验，真实通知授权与测试成功。该结果覆盖本机共享状态切换，专注模式、镜像显示器及其他待验场景继续保留。

通知模块的构建会将项目 MIT、Bun、官方 SDK、dsh-im 复用片段及依赖包的许可文本放入 App 的 `Contents/Resources/notification-runtime-NOTICES.txt`。小范围试用和公开分发均需在二进制下载点提供 Bun 所含 LGPL 组件的对应源码与重新构建资料；资料范围见 [SOURCE.txt](../third_party/bun/SOURCE.txt) 与 [归档说明](../third_party/bun/ARCHIVE-README.txt)。更换 Bun 构建版本时重新取得锁定的 WebKit、TinyCC 源码，核对许可与构建说明；公开分发前继续核对缺少许可全文的 SDK 包声明。参考 [Bun 官方许可说明](https://github.com/oven-sh/bun/blob/bun-v1.4.2/LICENSE.md)。
