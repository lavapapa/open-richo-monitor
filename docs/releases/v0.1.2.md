# RichoMonitor 0.1.2

系统中的应用名称统一为 RichoMonitor，RM 标志保持不变，仓库仍为 open-richo-monitor。沿用原有应用标识和用户数据目录，保留监控商品、通知账号与启动设置。

自动更新加入 Gitee 与 GitHub 双来源。启动时及运行期间每小时检查，选择两个来源中较新的版本；同版优先从 Gitee 下载，下载失败时尝试 GitHub。用户确认后按平台默认方式安装并重启，内置 Bun 和通知模块随完整应用更新。

提供 Mac Apple Silicon DMG 与 Windows x64 安装包。Mac 需要 macOS 13 或更新版本；尚未完成 Apple Developer ID 签名及公证，Windows 尚无 Authenticode 签名。首次安装步骤见 INSTALL.txt。未接入自动更新的旧版本需要手动安装一次。

安装包不含开发者账号或用户数据。Bun 第三方对应源码与重建资料提供独立可选下载：[第三方资料](https://github.com/lavapapa/open-richo-monitor/releases/tag/bun-v1.4.2-source)。
