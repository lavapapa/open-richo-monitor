# RichoMonitor 0.1.3 · 公开试用版

本版统一 macOS 与 Windows 的共享源码，整合通知渠道稳定性修复、扫码配对反馈、计划设置即时生效、补货与监控异常通知，以及通知配置页的布局调整。

## 安装

Apple Silicon Mac 下载 `RichoMonitor_0.1.3_aarch64.dmg`，将 RichoMonitor 拖入“应用程序”；需要 macOS 13 或更新版本。Windows x64 下载 `RichoMonitor_0.1.3_x64-setup.exe`。首次安装请阅读附件 `INSTALL.txt`，安装应用无需下载源码。

Mac 包采用临时签名，尚未完成 Developer ID 签名与 Apple 公证；Windows 包尚无 Authenticode 签名，首次打开可能受到系统拦截，请确认下载来源并按安装说明操作。两平台均沿用原应用标识和用户数据目录。

## 调整

微信、飞书、钉钉和企业微信共用独立通知运行时，完善连接恢复、授权失效、停用、取消配对与应用退出的处理。扫码后按各平台提示完成初始化；配对期间收到有效私信或群消息后回复“收到，配对成功！”。飞书可发现已加入的群聊，钉钉与企业微信按入站会话识别群聊。通知设置把创建人和可选群聊分开，提醒内容与保存操作固定在弹窗底部。

商品上架与补货分别呈现，已有记录时显示前后数量；监控异常通知包含失败原因、次数和持续时间。修复暂停后继续监控时使用过期计划的问题。Windows 补齐系统通知设置入口、按目标解析系统代理、小屏工作区适配和热键冲突时仍可展示突出提醒。

## 更新

启动时及每小时检查 Gitee 与 GitHub，选择较新的版本，同版优先从 Gitee 下载。界面提示后由用户点击“下载并重启”；更新包经独立更新签名验证，应用、通知脚本、内置 Bun 与许可声明整体替换，保留用户设置和会话。安装与重启期间监控短暂中断。

Mac 使用 `.app.tar.gz` 更新，Windows 使用同一 `.exe` 安装器；`.sig` 和 `latest.json` 供更新模块读取，手动安装无需另行下载。Bun 版本保持 1.4.2，运行时无需用户另外安装 Node 或 Bun。单一更新来源不可用时，另一个来源的有效检查仍可完成本次检查。

## 试用边界

本版针对 Apple Silicon Mac 与 Windows x64。跨日睡眠唤醒、真实网络切换、完整专注模式组合、真实注销登录、多日资源观察，以及 Windows 10、用户反馈的 Windows 11 23H2 和其他实机环境仍需补充验收。Windows 多显示器、锁屏解锁、缺少 WebView2 和更新中断的完整组合也保持待验，自动化回归与短时桌面测试分别记录。

Windows 的商城、图片和通知 SDK 支持 WinHTTP 按目标解析 PAC、WPAD 与静态绕过规则；PAC 返回多个备用代理时当前使用首选代理，尚未实现备用路线轮换。自动更新使用系统静态 HTTP/HTTPS 代理，PAC 与自动发现代理暂未支持；更新服务无法访问时可从发布页手动下载。

Bun 及其 LGPL 组件的对应源码与重建资料提供[独立可选下载](https://github.com/lavapapa/open-richo-monitor/releases/tag/bun-v1.4.2-source)。安装包不包含开发者通知账号或用户数据。项目采用 MIT，本应用与理光官方无隶属关系。
