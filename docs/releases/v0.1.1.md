# open-richo-monitor 0.1.1

监控理光商城商品上架、补货与库存增加，支持系统通知、全屏突出提醒，以及飞书、企业微信、钉钉和微信通知渠道。

## 安装

Apple Silicon Mac 下载文件名含 `aarch64.dmg` 的安装包，将 App 拖入“应用程序”后打开，macOS 要求 13.0 或更新版本。Windows x64 下载 `x64-setup.exe`。安装应用无需下载项目源码或 Bun 源码资料。

当前 Mac 安装包采用本地签名，尚未经过 Apple Developer ID 公证；首次打开可能被 Gatekeeper 拦截，可按安装包内说明在“系统设置 → 隐私与安全性”中允许打开。Windows 安装包尚无 Authenticode 签名，可能出现 SmartScreen 提示。请从本项目发布页获取安装包。

## 自动更新

启动时及运行期间每小时检查 GitHub 更新。发现新版本后在界面提示，用户点击“下载并重启”开始更新。更新签名验证通过后，默认安装流程将 App、通知脚本和内置 Bun 作为整体替换，保留用户设置与渠道会话。

先前的 0.1.0 版本需要手动安装本版一次，之后可使用自动更新。安装期间监控会短暂中断。更新检查与下载遵循系统静态 HTTPS 代理；PAC 与自动发现暂未支持，无法连接 GitHub 时可从发布页手动下载。


Bun 所含 LGPL 组件的对应源码资料独立放在 [可选资料发布页](https://github.com/lavapapa/open-richo-monitor/releases/tag/bun-v1.4.2-source)。
