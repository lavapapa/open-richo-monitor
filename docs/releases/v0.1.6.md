# RichoMonitor 0.1.6

## 本轮调整

- 全屏突出提醒改用黄色背景，上下警示带反向连续滚动，商品信息保持稳定；系统减少动态效果时停止滚动。
- 警示带随当前库存更新，零库存时如实显示，适配小尺寸窗口。
- 引导页、设置页及相关提示统一使用“开机自启动”。
- 更新状态移至左侧栏底部：自动下载时显示进度，下载完成后可点击“立即更新”；自动安装继续等待监控与扫描空闲。
- 精简最近消息中的检查结果文案，移除冒号。

## 安装文件

| 电脑 | 文件 |
| --- | --- |
| Mac · Apple Silicon | `RichoMonitor_0.1.6_aarch64.dmg` |
| Mac · Intel | `RichoMonitor_0.1.6_x64.dmg` |
| Windows · 64 位 | `RichoMonitor_0.1.6_x64-setup.exe` |

Mac 要求 macOS 13 或更新系统。Mac 尚无 Developer ID 签名及 Apple 公证，Windows 尚无 Authenticode 签名，首次安装参见附带的安装说明。

Bun 保持 1.4.2。对应源码及重建资料提供[独立可选下载](https://github.com/lavapapa/open-richo-monitor/releases/tag/bun-v1.4.2-source)。安装应用无需下载源码。
