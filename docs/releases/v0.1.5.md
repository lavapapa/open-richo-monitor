# RichoMonitor 0.1.5

## 本版调整

- 增加配置变更提醒，合并连续的商品、计划及检查间隔调整后发送最终变化；通知渠道可单独选择此提醒。
- 测试通知展示当前监控商品、星期、计划时段及检查间隔。
- 通知正文精简商品编号与时间标签，时间保留到毫秒。
- 新功能介绍采用固定尺寸的逐项确认流程，跨版本升级按未确认项依次展示。
- 增加可选的 PostHog 使用统计及设置入口，页面说明发送和排除的数据范围。
- 引导第三页的统计选择位于完成按钮左侧，无选择记录时默认勾选，重新引导沿用用户保存的选择。
- 反馈改用 Tally 表单，支持提交意见、可选截图及联系方式。
- 调整 GitHub Star 与打赏作者入口的布局和样式。
- 限制检查与消息历史数量，清理未使用的商品图片，减少长期运行的磁盘占用。

## 安装文件

| 电脑 | 文件 |
| --- | --- |
| Mac · Apple Silicon | `RichoMonitor_0.1.5_aarch64.dmg` |
| Mac · Intel | `RichoMonitor_0.1.5_x64.dmg` |
| Windows · 64 位 | `RichoMonitor_0.1.5_x64-setup.exe` |

Mac 要求 macOS 13 或更新系统。Mac 尚无 Developer ID 签名及 Apple 公证，Windows 尚无 Authenticode 签名，首次安装参见附带的安装说明。

Bun 保持 1.4.2。对应源码及重建资料提供[独立可选下载](https://github.com/lavapapa/open-richo-monitor/releases/tag/bun-v1.4.2-source)。安装应用无需下载源码。
