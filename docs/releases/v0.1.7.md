# RichoMonitor 0.1.7

## 本轮调整

- macOS 主窗口采用一体式布局，隐藏顶部重复的应用名，侧栏延伸至窗口顶端；主内容与顶部同色，保留系统窗口按钮和拖动区域。
- 侧栏恢复大 RM 字标与下方完整产品名，保留原有品牌布局。
- 增加 macOS 原生中文菜单、设置与商品搜索快捷键；编辑、最小化、隐藏和关闭操作沿用系统习惯。
- 主窗口记忆尺寸、位置和缩放状态；页面切换保留各自滚动位置。
- 统一设置分组、按钮与输入框密度，优化明暗主题、商品图片边界和弹窗页签。
- 按钮增加可中断的按压反馈，系统减少动态效果时保持静止。
- 改善侧栏键盘导航、输入与消息复制、Esc 取消确认后的焦点恢复；修复顶部拖动区遮挡滚动控件和窄窗口引导页底部裁切。
- 修复从另一实例取消商品扫描时，扫描任务退出后取消状态可能未及时发布的问题。

## 安装文件

| 电脑 | 文件 |
| --- | --- |
| Mac · Apple Silicon | `RichoMonitor_0.1.7_aarch64.dmg` |
| Mac · Intel | `RichoMonitor_0.1.7_x64.dmg` |
| Windows · 64 位 | `RichoMonitor_0.1.7_x64-setup.exe` |

Mac 要求 macOS 13 或更新系统。Mac 尚无 Developer ID 签名及 Apple 公证，Windows 尚无 Authenticode 签名，首次安装参见附带的安装说明。

Bun 保持 1.4.2。对应源码及重建资料提供[独立可选下载](https://github.com/lavapapa/open-richo-monitor/releases/tag/bun-v1.4.2-source)。安装应用无需下载源码。
