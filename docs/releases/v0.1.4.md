# RichoMonitor 0.1.4 · 公开试用版

## 下载

| 电脑 | 安装文件 |
| --- | --- |
| Mac · Apple Silicon | `RichoMonitor_0.1.4_aarch64.dmg` |
| Mac · Intel | `RichoMonitor_0.1.4_x64.dmg` |
| Windows · 64 位 | `RichoMonitor_0.1.4_x64-setup.exe` |

Mac 将 App 拖入“应用程序”，要求 macOS 13 或更新版本。首次安装参见附件 `INSTALL.txt`。Mac 尚无 Developer ID 签名及 Apple 公证，Windows 尚无 Authenticode 签名，系统可能提示确认来源。

## 本版调整

- 默认下载更新，等监控停止、暂停或计划时段外再安装；保留监控意图，关窗后继续在后台处理。手动立即更新需确认中断。
- 两个更新来源并行检查，最多等待五秒收集已取得的结果；无有效结果时继续等待，取得首份有效信息后完成。
- 通知的系统代理选项移入其他设置，独立于商城请求；系统没有代理时自然直连。
- 移除每秒请求数限制。检查间隔表示请求完成后的等待时间，支持零等待。
- 补货通知显示已有的前后数量；监控异常通知补充原因、失败次数和持续时间。
- 优化通知连接恢复、突出提醒与 Windows 按键处理。
- 修复状态页右侧分隔线在“管理商品”入口附近中断的问题，商品与消息面板分别滚动。
- 新增购买成功后的评价、反馈与打赏入口，设置底部提供“打赏作者”；README 增加 Hero 图与三平台直接下载入口。

## 更新与许可

从本版起默认在监控空闲时自动更新；上一版用户按照原更新提示完成本次升级后即可使用此机制。更新包经过独立更新签名验证，App、通知脚本、Bun 及许可声明整体替换，沿用原用户数据目录。安装期间监控会短暂中断。

`.sig`、`.app.tar.gz` 和 `latest.json` 供更新模块读取。手动安装下载上表对应文件即可。Bun 保持 1.4.2，其对应源码与重新构建资料提供[独立可选下载](https://github.com/lavapapa/open-richo-monitor/releases/tag/bun-v1.4.2-source)。项目采用 MIT，与理光官方无隶属关系。

## 试用范围

已完成 Apple Silicon Mac 与 Windows 11 虚拟机的隔离升级实测，包括监控期间等待、闲时安装、重启后意图与记录保留，以及已安装包内 Bun 验证。Intel Mac 按基础构建及启动验收范围提供。

真实通知渠道在本轮升级后的投递、跨日睡眠、断网与网络切换、完整专注模式组合、全屏应用、实际注销登录、多日资源变化，以及其他 Windows 实机、锁屏与多显示器组合仍待验。自动化回归和短时测试分别记录，详见项目发版验收清单。自动更新使用系统静态 HTTP/HTTPS 代理；无法访问更新服务时可手动下载安装包。
